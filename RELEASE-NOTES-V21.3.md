# MaintenanceOS V21.3 — Parts Glass UI

Visual-only refinement based on the working V21.2 Parts Intelligence release.

## Changes
- Corrected inventory image distortion by preserving source-image aspect ratio with `object-fit: contain`.
- Reworked part media into a restrained glass tile with translucent layering, highlight, depth and MaintenanceOS teal illumination.
- Improved card structure and consistent action positioning across cards with different description lengths.
- Increased Supplier-link contrast from dark blue to the MaintenanceOS cyan/teal accent, including a brighter hover state.
- Improved metadata, stock-label and notes legibility against the dark application background.
- Added responsive glass-card sizing for smaller screens.
- Repair/inventory/database behaviour is unchanged from V21.2.

## Database
No migration required.
