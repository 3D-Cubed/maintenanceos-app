MaintenanceOS V22.1 — PWA INSTALLATION

1. Replace the existing project source with this release.
2. Preserve the existing .env / Vercel environment variables.
3. From the project directory run:
   npm install
4. Verify the production build:
   npm run build
5. Commit and push:
   git add .
   git commit -m "MaintenanceOS V22.1 mobile PWA"
   git push origin main
6. Allow Vercel to deploy.

PHONE INSTALLATION — ANDROID / CHROME / EDGE
1. Open the live Maintenance Hub URL.
2. Use the browser's Install app / Add to home screen option, or use the Install App button when shown.
3. Launch Maintenance Hub from the new home-screen icon.

IPHONE / IPAD
1. Open Maintenance Hub in Safari.
2. Tap Share.
3. Select Add to Home Screen.
4. Launch from the new Maintenance Hub icon.

ACCEPTANCE TESTS
- Desktop still loads normally.
- Phone opens in a standalone app window after installation.
- Bottom navigation remains usable.
- QR deep links still open the correct asset.
- Fault photo input can use the phone camera where supported.
- Supabase live data remains network-backed and is not cached by the service worker.
