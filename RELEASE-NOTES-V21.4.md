# MaintenanceOS V21.4 — Atom3D Signature Parts UI

Visual-only refinement built on V21.3/V21.2 functionality.

- Reworked Parts cards to match the dark Atom3D / MaintenanceOS visual language.
- Increased glass media tile presence while preserving source-image aspect ratio with `object-fit: contain`.
- Added restrained glass depth, edge highlights, teal illumination and card hover lift.
- Improved typography, stock hierarchy and metadata rhythm.
- Standardised View history, Adjust stock and Supplier as matching controls.
- Supplier is now a proper high-contrast button with an external-link cue.
- Notes are clamped to keep the inventory grid disciplined and consistent.
- No database migration. No Parts/Repair business logic changed.
